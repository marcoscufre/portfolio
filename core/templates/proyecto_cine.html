PROYECTO FULLSTACK

Gestión de Cine

Plataforma integral desarrollada en Django para la gestión eficiente de salas de cine, automatizando desde la programación de funciones hasta el procesamiento de ventas y promociones.

GitHub Repo
Django
JavaScript
MySQL
Bootstrap 5

El Desafío

Desarrollar una arquitectura escalable que maneje la concurrencia en la venta de entradas, garantizando la integridad de los datos entre múltiples aplicaciones interconectadas (películas, funciones, ventas, usuarios).

Enfoque Técnico

Implementación de un sistema de control de acceso basado en roles (RBAC) y consultas SQL optimizadas para reportes financieros y gestión de inventario de productos.

Características Clave

Programación Automática

Lógica inteligente para el cálculo de horarios y duraciones, evitando solapamientos en las salas disponibles.

Integración con TMDb API

Sincronización con bases de datos externas para enriquecer el catálogo con metadatos, sinopsis y pósters oficiales.

Motor de Promociones

Sistema flexible de descuentos porcentuales aplicables por fechas específicas y tipos de funciones seleccionadas.

Admin Dashboard

Interfaz administrativa centralizada para el monitoreo en tiempo real de ventas, usuarios y rendimiento de películas.
