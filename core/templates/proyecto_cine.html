Cinema Management
University Project | Lead Developer
FULL-STACK DEVELOPMENT

Movie Theater Management System

Plataforma integral para la gestión de salas de cine, incluyendo cartelera dinámica, reserva de entradas y roles de usuario avanzados.

Django
JavaScript
MySQL
Bootstrap 5

The Challenge

El reto consistió en desarrollar un sistema que pudiera manejar simultáneamente la venta de entradas en tiempo real y la administración de la cartelera mediante la integración con APIs externas de películas para mantener la información siempre actualizada.

Technical Focus

Implementación de un sistema de roles granular para staff y clientes, garantizando la seguridad en las transacciones de ventas y la integridad de la base de datos MySQL.

Key Metrics
API Sync Speed< 500ms
User Roles3 Types

Key Features

Dynamic Billboard

Integración con TMDB API para obtener detalles, imágenes y trailers de películas automáticamente.

Role Management

Interfaces diferenciadas para Administradores (ventas, salas) y Clientes (compras, perfil).

CRUD System

Gestión completa de funciones, películas, salas y usuarios desde un panel de control intuitivo.

Responsive UI

Diseño adaptado a todos los dispositivos utilizando Bootstrap 5 para una experiencia fluida.
