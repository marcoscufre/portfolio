Pagina Web para un Cine desarrollada en Django

Incluye sistema de administracion y autenticacion , sistema de compras y el uso de una API externa para obtener las peliculas

Descripcion

Este proyecto es un sistema integral de gestión de cine que permite:

  • Gestión de Películas: Administrar catálogo de películas con información detallada
  • Gestión de Funciones: Programar funciones con horarios y salas
  • Sistema de Ventas: Procesar ventas de entradas con diferentes métodos de pago
  • Gestión de Usuarios: Sistema de autenticación y perfiles de usuario
  • Promociones: Sistema de descuentos y promociones especiales
  • Productos: Gestión de productos adicionales (concesiones)
  • Reportes: Dashboard para administradores y usuarios

Tecnologias Usadas

  • Python: Lenguaje de programación principal
  • Django: Framework web para el desarrollo del backend
  • MySQL: Base de datos elegida para el proyecto
  • Bootstrap: Framework CSS para el diseño responsivo
  • HTML/CSS: Estructura y estilo de la página web
  • JavaScript: Interactividad en el frontend incluyendo asincronía con AJAX
  • API Externa: Integración para obtener información de películas
  • Git: Control de versiones y colaboración en el desarrollo
