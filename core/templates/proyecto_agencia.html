Sistema integral para gestión de concesionarias

El Desafío

Centralizar procesos que normalmente viven separados: inventario, clientes, ventas, pagos, documentación vehicular y permisos internos. El objetivo fue mantener una interfaz clara para uso diario sin sacrificar consistencia de datos.

Enfoque Técnico

Backend modular con apps Django para usuarios, clientes, vehículos, ventas y gestoría; API REST consumida por Vue; wrapper Electron que inicia y supervisa los servicios locales antes de abrir la ventana principal.

Arquitectura Técnica
BackendDjango + DRF
FrontendVue 3 + Vite
Desktop ShellElectron

Capacidades Clave

Inventario con estados

Control de vehículos disponibles, reservados, vendidos, en preparación o recibidos como parte de pago, con imágenes y datos comerciales.

CRM y empleados

Gestión de clientes, vendedores y usuarios internos con roles de administrador y staff para separar responsabilidades operativas.

Ventas atómicas

Registro de operaciones con transacciones, validación de disponibilidad, pagos mixtos, financiación y vehículos tomados como parte de pago.

Gestoría vehicular

Seguimiento de formularios, VTV, libre deuda, multas, patentes, gestores asignados y observaciones por cada vehículo.
