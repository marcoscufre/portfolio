Sistema de Gestión para Agencia de Autos

Aplicación de escritorio desarrollada en Python con PyQt5, orientada a automatizar procesos en pequeñas agencias de venta de vehículos.

Descripción

Esta herramienta permite gestionar de manera integral el inventario de vehículos, los clientes, las ventas y la generación de reportes automatizados en Excel. Diseñada con una interfaz moderna y adaptable, busca optimizar los tiempos administrativos de una agencia de autos tradicional.

Tecnologías utilizadas

  • Python: Lenguaje de programación principal
  • SQL Server: Base de datos utilizada
  • Pyodbc: Conector ODBC para Python
  • PyQt5: Framework para la interfaz de usuario
  • Openpyxl: Librería para manipulación de archivos Excel en Python

Funcionalidades principales

  • Gestión de vehículos, Operaciones Crud.
  • Registro y seguimiento de ventas.
  • Consulta y filtrado de clientes.
  • Exportación de reportes mensuales en formato Excel.
  • Login de acceso para garantizar privacidad de datos.
