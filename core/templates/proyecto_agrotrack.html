AgroTrack — Sistema de Gestión Agrícola

Plataforma full-stack que moderniza la administración de establecimientos agropecuarios, controlando el ciclo de vida de cultivos, aplicaciones de insumos fitosanitarios, lotes espaciales y reportes de certificación.

Repositorio Privado (Bajo NDA)
GlobalGAP Trazabilidad Agrícola
PostGIS Lotes Georreferenciados
100% Control de Carencias
SPA + API Vue 3 + DRF Core
El Desafío del Sector

Trazabilidad Precisa y Manejo de Lotes

La gestión agrícola tradicional depende frecuentemente de anotaciones en papel o planillas desactualizadas, provocando errores en las dosis de aplicación, vencimiento de periodos de carencia y dificultades para certificar cosechas bajo normas de exportación.

Con AgroTrack desarrollé una API robusta en Django REST Framework respaldada por PostgreSQL, combinada con una Single Page Application reactiva en Vue 3 que permite a los agrónomos delimitar lotes, registrar labores de siembra y monitorear el stock de insumos en tiempo real.

Arquitectura Técnica
Backend REST Django REST Framework + JWT Auth
Base de Datos PostgreSQL con Índices Espaciales
Frontend Reactivo Vue 3 + Vite + Leaflet Maps

Capacidades Clave del Sistema

Mapeo y Delimitación de Lotes

Integración de capas vectoriales con Leaflet para visualizar parcelas, superficie en hectáreas y estado del cultivo según rotación estacional.

Cálculo de Periodos de Carencia

Algoritmo que calcula automáticamente la fecha segura de cosecha tras cada aplicación química, previniendo la contaminación de productos y garantizando inocuidad alimentaria.

Control de Stock e Insumos

Módulo de depósitos con descuento automático de fitosanitarios, semillas y fertilizantes conforme se asientan las órdenes de trabajo en el campo.

Reportes Auditables en PDF

Generación de informes de trazabilidad por lote y campaña para presentar ante organismos de control de sanidad y clientes agroexportadores.
