PROYECTO DESTACADO

Sistema de Gestión Agrícola

Modernizando el seguimiento agrícola tradicional para reducir desperdicios y mejorar el rendimiento de los cultivos mediante análisis de datos avanzado y monitoreo espacial.

Django REST
Vue 3
PostgreSQL
Leaflet
JWT Auth

El Desafío

La gestión agrícola intensiva tradicional a menudo depende de registros manuales y datos fragmentados, lo que conduce a un desperdicio significativo de recursos y respuestas tardías a los estresores de los cultivos.

La Solución

AgroTrack unifica la gestión mediante una SPA en Vue 3 móvil y una API Django. Automatiza la trazabilidad fitosanitaria (GlobalGAP), calcula periodos de carencia de productos y genera reportes de calidad en PDF descargables.

Enfoque Técnico

Manejo de actualizaciones de datos de alta frecuencia y ejecución de consultas espaciales complejas con PostgreSQL/PostGIS.

Arquitectura Técnica
BackendDjango REST Framework
FrontendVue 3 + Vite + Pinia
Base de DatosPostgreSQL + PostGIS

Resultados e Impacto

100% Trazabilidad

Actividades, labores y aplicaciones fitosanitarias digitalizadas y georreferenciadas bajo estándares GlobalGAP.

Instantánea Reportes de Calidad

Generación automática de certificados de muestras en PDF vía WeasyPrint listos para auditoría de calidad.

Paramétrica Control de Calidad

Clasificación automatizada y objetiva de cosechas basada en parámetros específicos de cada cultivo.

Características Clave

Trazado GIS & Interacción

Trazado interactivo de parcelas georreferenciadas utilizando Leaflet.js y Mapbox, permitiendo calcular superficies directamente sobre el mapa.

Clasificación Paramétrica de Calidad

Algoritmo del "eslabón más débil" (Weakest Link) que evalúa múltiples parámetros (Brix, Calibre, Firmeza) y clasifica automáticamente la producción.

Lógica Transaccional en Campañas

Transacciones atómicas que validan solapamientos de cultivos en lotes y crean de manera automática labores de siembra integradas.

Arquitectura Desacoplada y JWT

Comunicación stateless segura entre cliente Vue 3 y API Django mediante interceptores Axios que manejan la renovación silenciosa de tokens.
