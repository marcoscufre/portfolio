AgroTrack

Sistema de Gestión Agrícola para Cultivos Intensivos

Plataforma integral desarrollada con Django REST Framework y Vue 3 para la administración eficiente de establecimientos agrícolas.

Descripción del Proyecto

AgroTrack es una solución robusta diseñada para optimizar la gestión de cultivos intensivos. El sistema permite el seguimiento detallado de lotes, labores culturales, aplicaciones de insumos y monitoreo de condiciones climáticas, facilitando la toma de decisiones basada en datos.

  • Gestión Geoespacial: Trazado de multipolígonos en mapa interactivo (Leaflet-draw) para delimitar lotes y establecimientos.
  • Servicios Externos: Consumo de APIs de clima y geolocalización en tiempo real.
  • Seguridad: Autenticación robusta mediante JWT con cookies HttpOnly.
  • Datos Complejos: Uso de JSONField/JSONBinary en PostgreSQL para estructuras de datos flexibles.
  • Documentación: API completamente documentada con Swagger/OpenAPI.

Stack Tecnológico

Backend
  • Python & Django REST Framework
  • PostgreSQL (con extensiones Geoespaciales)
  • Django TestCase (Testing)
  • JWT Auth (HttpOnly Cookies)
Frontend
  • Vue 3 (Composition API)
  • Vite & Pinia (State Management)
  • Leaflet & Leaflet-draw (Mapas)
  • Cypress (E2E Testing)
