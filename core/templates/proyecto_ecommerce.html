Proyecto Ecommerce Actualmente en desarrollo Django y Angular

En estos momentos incluye integracion con swagger para la documentacion de la API, autenticacion con JWT , pedidos , catalogo de productos , categorias y un carrito de compras.

Descripción

Este proyecto es un sistema de ecommerce que permitira:

  • Gestión de Productos: Administrar catálogo de productos con información detallada
  • Gestión de Pedidos: Procesar pedidos y gestionar el estado de los mismos
  • Sistema de Carrito: Permitir a los usuarios agregar productos al carrito y realizar compras
  • Autenticación: Sistema de autenticación y perfiles de usuario
  • API Documentada: Integración con Swagger para documentación de la API
  • Seguridad: Implementación de autenticación JWT para seguridad en las transacciones
  • Interfaz de Usuario: Desarrollo de una interfaz amigable y responsiva

Tecnologías Usadas

  • Python: Lenguaje de programación principal
  • Django: Framework web para el desarrollo del backend
  • Angular: Framework para el desarrollo del frontend
  • TypeScript: Lenguaje principal en Angular
  • JSON: Formato para intercambio de datos entre el frontend y el backend
  • PostgreSQL: Base de datos elegida para el proyecto
  • Bootstrap: Framework CSS para el diseño responsivo
  • HTML/CSS: Tecnologías básicas para la maquetación
  • drf-yasg: Libreria para implementar swagger en Django REST Framework

Funcionalidades Principales a conseguir

  • Registro de usuarios y autenticación
  • Búsqueda y filtrado de productos
  • Carrito de compras y gestión de pedidos
  • Integración de métodos de pago
  • Panel de administración para gestión de productos y pedidos
  • Dashboard con estadísticas de ventas, usuarios y productos
  • Manejo de roles de usuario
  • Operaciones CRUD Administrativas

Desafios Tecnicos

Algunos de los desafíos técnicos relevantes fueron aprender TypeScript y Angular desde cero de forma autodidacta. Ademas de comprender bien la arquitectura Rest y la implementación de JWT para la autenticación y autorización de usuarios. Otro desafío fue la integración de Swagger para documentar la API de forma efectiva, lo que permite una mejor comprensión de las rutas y los datos que se manejan en el sistema. Es importante destacar que este proyecto es un trabajo en progreso y se espera que continúe evolucionando con nuevas funcionalidades y mejoras en la experiencia del usuario.
