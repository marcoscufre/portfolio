APP LOGISTICA FULLSTACK

Planificador inteligente para rutas de carga

Plataforma stateless para planificar viajes de larga distancia, calcular rutas reales, insertar paradas de combustible y generar cronogramas compatibles con reglas HOS para conductores.

Django
React 19
Vite
Pydantic
MapLibre

El Desafío

Coordinar geocodificación, routing, combustible y cumplimiento HOS en una respuesta clara para el usuario, sin persistencia ni base de datos, dejando que cada plan se calcule bajo demanda.

Enfoque Técnico

Orquestación backend con servicios desacoplados: LocationIQ para autocompletado, OpenRouteService para rutas, MapTiler para visualización y motores propios para HOS, combustible y logs diarios.

Arquitectura Técnica
BackendDjango + Pydantic
FrontendReact + Tailwind
PersistenciaStateless

Capacidades Clave

Motor HOS

Simula reglas FMCSA como 11 horas de conducción, ventana de 14 horas, descanso de 30 minutos y ciclo 70h/8d.

Routing Real

Resuelve direcciones, calcula legs del viaje y renderiza geometrías de carretera con marcadores de origen, pickup, destino y combustible.

Plan de Combustible

Inserta paradas técnicas antes de superar 1,000 millas, integrándolas al cronograma operativo del viaje.

Logs Diarios

Convierte la línea de tiempo continua en registros diarios visuales tipo ELD, listos para auditar descansos y conducción.
